### 2. 速凝掩体 🧱
投掷快速凝固混凝土，瞬间生成可挡伤害的掩体，支持**横向 / 竖向**切换。家人们，这墙是真能救命，绝绝子。

### 3. 复合型燃烧弹 🔥
触地即炸，持续灼烧，还能**烧毁敌方速凝掩体**，封路、逼走位、排点一条龙。

### 4. 被动 · 久经沙场 🛡️
对**骨折**、**减速**等负面效果抗性拉满，跑得快、站得稳，老六都追不上。
